About This Project

The Library Management System is a student-created front-end web application built using HTML, CSS, and Bootstrap. Its primary goal is to simulate how a simple digital system can be used to manage books, track purchases, and maintain a list of library members. This project is purely for educational purposes at Frantz Fanon University.

Features include:

  • Book catalog display
  • Member purchase records
  • Responsive navigation menu
  • Forms for user login and registration
